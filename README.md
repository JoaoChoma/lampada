# Projeto Lâmpada — HTML, CSS e JavaScript

Material prático para uma aula introdutória sobre:

- centralização de uma DIV com Flexbox;
- DOM;
- eventos de clique;
- funções JavaScript;
- alteração do atributo `src` de uma imagem.

## Como executar

1. Extraia o ZIP.
2. Abra `index.html` em um navegador.
3. Clique em **Acender** e **Apagar**.
4. Consulte `aula_lampada.md` para seguir a aula e os exercícios.

Não é necessário servidor web para esta versão da atividade.
